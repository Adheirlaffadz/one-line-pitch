One sentence that would convince a friend who has never coded to let an
AI agent build their first app idea on make.fun.

> Tell me your app idea in one sentence, and I'll watch an AI agent build it for you on make.fun tonight — no code, no cost, no risk, just your idea coming alive.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes that single
sentence — 160 characters — to `/output/entry.txt`.
